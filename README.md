# 智能任务管理系统

一个完整的任务管理网站：Node.js（后端）+ React（前端）+ Supabase（PostgreSQL 云数据库）。

## 功能一览

- 输入框 + 优先级下拉（高 / 中 / 低）添加任务
- 任务列表按创建时间倒序显示（最新在最上面）
- 每条任务显示：标题、优先级标签、完成状态
- 完成 / 未完成 切换按钮、删除按钮
- 已完成任务文字自动加删除线、颜色变淡
- 按优先级筛选：全部 / 高 / 中 / 低
- 数据存在云端数据库，关掉浏览器再打开数据还在

## 本地运行（3 步）

```bash
# 1. 安装依赖（第一次运行）
npm run install:all

# 2. 构建前端（把 React 页面编译好放到 server/public）
npm run build

# 3. 启动服务
npm start
```

打开浏览器访问：http://localhost:3000

> 小提示：没配 Supabase 环境变量时，后端会自动使用本地文件 `server/data/tasks.json`
> 模拟数据库（教学演示模式，数据不会因为重启丢失）。配了之后自动切换到云端数据库。

## 连接你自己的 Supabase

1. 在 [supabase.com](https://supabase.com) 注册并创建项目
2. 在 SQL Editor 执行建表 SQL 和 RLS 策略 SQL（见下方）
3. 拿到 **Project URL** 和 **Publishable key**（`sb_publishable_...` 开头）
4. 启动前配置环境变量：

```bash
export SUPABASE_URL="https://你的项目ID.supabase.co"
export SUPABASE_ANON_KEY="sb_publishable_你的key"
npm start
```

### 建表 SQL

```sql
create table if not exists tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  priority text not null default '中' check (priority in ('高', '中', '低')),
  completed boolean not null default false,
  created_at timestamptz not null default now()
);
```

### RLS 策略 SQL（不开的话写不进数据）

```sql
alter table tasks enable row level security;

create policy "Allow anon read" on tasks for select using (true);
create policy "Allow anon insert" on tasks for insert with check (true);
create policy "Allow anon update" on tasks for update using (true) with check (true);
create policy "Allow anon delete" on tasks for delete using (true);
```

## 部署到 Vercel

1. 把代码推到 GitHub 公开仓库
2. 在 [vercel.com](https://vercel.com) 导入该仓库
3. 添加环境变量（变量名不能改）：

| Name | Value |
| --- | --- |
| SUPABASE_URL | `https://你的项目ID.supabase.co` |
| SUPABASE_ANON_KEY | `sb_publishable_你的key` |

4. 点 Deploy，等 1～3 分钟即可访问 `https://xxx.vercel.app`

## API 接口速查

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | /api/tasks | 查询列表（?priority=高 可筛选） |
| POST | /api/tasks | 添加任务 `{title, priority}` |
| PATCH | /api/tasks/:id | 切换完成状态 `{completed}` |
| DELETE | /api/tasks/:id | 删除任务 |
